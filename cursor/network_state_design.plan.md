# NetworkState（通信品質SSOT）実装方針\n\n## 目的\n- `ChatRoomState` に通信品質を直持ちせず、ユーザー（=1 PeerConnection）単位で独立管理。\n- 将来的な多者通話を見据え、拡張/疎結合を担保。\n\n## 追加する型/ストア\n### 型定義（最小）\n```ts\nexport type QualityLevel = \"high\" | \"medium\" | \"low\" | \"poor\";\n\nexport type NetworkState = {\n  peerId: number | null;\n  peerConnection: RTCPeerConnection | null;\n  localStream: MediaStream | null;\n  remoteStream: MediaStream | null;\n  bitrateKbps: number | null;\n  packetLoss: number | null; // 0-1 or % 換算値（設計で統一）\n  rttMs: number | null;\n  qualityLevel: QualityLevel;\n  setPeerConnection: (pc: RTCPeerConnection | null) => void;\n  setStreams: (local: MediaStream | null, remote: MediaStream | null) => void;\n  updateMetrics: (metrics: Partial<Pick<NetworkState,\n    \"bitrateKbps\" | \"packetLoss\" | \"rttMs\" | \"qualityLevel\">>) => void;\n};\n```\n\n### ストア設計（Zustand / 1ユーザー=1ストア）\n- 単一ユーザー監視用の `useNetworkState(peerId)` を作る（内部は Map 管理 or 個別ストア）。\n- まずは単純化のため、`useNetworkStateStore` として `Map<number, NetworkState>` を持つグローバルストアを用意。\n\n```ts\n// types/networkStore.ts（イメージ）\nexport type NetworkStoreState = {\n  byPeerId: Map<number, NetworkState>;\n  ensure: (peerId: number) => NetworkState; // なければ作って返す\n  remove: (peerId: number) => void;\n  reset: () => void;\n};\n```\n\n## ChatRoomState との関係\n- `ChatRoomState` は既存の `session` を維持。\n- 必要であれば `peerId -> NetworkState` 参照（キーのみ）を持つが、推奨は「依存しない」。\n- 画面/UI は状況に応じて `useChatRoomStore` と `useNetworkStateStore` を併用。\n\n## 取得ロジック（getStats 監視）\n### モニタ関数\n- `monitorNetworkQuality(peerId: number, intervalMs = 2000): () => void`\n  - `setInterval` で `pc.getStats()` を定期取得。\n  - 主要メトリクスに集約→ストア更新。\n  - 返り値は `clearInterval` を行う停止関数。\n\n### getStats の集約例\n- audio/video の `outbound-rtp`/`inbound-rtp` レポートから算出。\n  - bitrateKbps: `bytesSent/bytesReceived` の差分/経過秒×8/1000\n  - packetLoss: `packetsLost/(packetsLost + packetsReceived)`（受信側）\n  - rttMs: `currentRoundTripTime * 1000`（`candidate-pair` or `remote-inbound-rtp`）\n- 集約ルールは関数に分離（将来拡張しやすく）。\n\n```ts\nfunction deriveQualityLevel({ bitrateKbps, packetLoss, rttMs }): QualityLevel {\n  // 例: ざっくり閾値（後でチューニング可能）\n  if ((bitrateKbps ?? 0) > 1500 && (packetLoss ?? 0) < 0.02 && (rttMs ?? 0) < 100) return \"high\";\n  if ((bitrateKbps ?? 0) > 800 && (packetLoss ?? 0) < 0.05 && (rttMs ?? 0) < 200) return \"medium\";\n  if ((bitrateKbps ?? 0) > 300 && (packetLoss ?? 0) < 0.1 && (rttMs ?? 0) < 400) return \"low\";\n  return \"poor\";\n}\n```\n\n## API/ライフサイクル\n1) 通話確立時（発信/受信）\n- `ensure(peerId)` で NetworkState を用意\n- `setPeerConnection(pc)`, `setStreams(local, remote)` を即反映\n- `stop = monitorNetworkQuality(peerId)` を開始\n\n2) 通話終了/退出時\n- `stop()` で監視停止\n- `remove(peerId)` または `reset()`\n- `localStream.getTracks().forEach(t=>t.stop())` 等は既存の退出ハンドラで実施\n\n## UI 連携\n- 例: インジケータ\n```tsx\nconst ns = useNetworkState(peerId);
